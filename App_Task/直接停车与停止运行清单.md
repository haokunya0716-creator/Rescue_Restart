## 当前正式复检的停车与恢复（2026-10-24）

```text
绿色完成原停车复核，保持零轮速
    ↓ 同次落框并发送新view_id，开始第一次500 ms复检
    ├─ 提前成功/失败 → 保存终态及失败原因，不再读图；落框未满500 ms继续停车
    ├─ 满500 ms仍无终态 → 超时失败，不接纳此时才处理的新图
    └─ 落框已满500 ms → 使用已保存结果，不追加等待
           ├─ 成功 → 新视角旋转寻找本队整区
           └─ 失败 → 新视角第二次复检，独立500 ms，继续停车
                  ├─ 提前成功 → 立即旋转找本队整区，无第二次机械等待
                  ├─ 多件/非绿色 → 原前推5 cm、抬框并转360°、旋转找绿色
                  └─ 三图无命中/500 ms超时 → 抬框同时15 cm/s后退1秒、旋转找绿色
```

已有终态不会被后续图像或500 ms超时覆盖。整轮180秒优先于缓存结果、重试和恢复分支停车，起点及原启动搜索例外保持；普通复检失败本身不退出至空闲。摄像头50°、机械等待宏500 ms、其它参数和测试入口沿用现状。本节替代下方历史快照中的先落框等待、每次3秒等时序描述；没有新增停车或保护判断。
